# Chronicle

This package contains the current Chronicle website files with the V1-inspired visual theme applied to `assets/style.css` only.

## Structure

- `index.html`
- `movies.html`
- `anime.html`
- `about.html`
- `connect.html`
- `assets/style.css` — updated V1-inspired theme
- `assets/script.js`
- `assets/effects.js`
- `assets/movies-data.js`
- `assets/anime-data.js`

## Deploying on GitHub Pages

Upload/replace these files in the repository while preserving the root HTML files and the `assets` folder structure. Back up the existing repository first. No TMDB or AniList API integration has been added in this package.
